## Добавленные настройки

- **Gooby** после транспорта: один исходный `CompactDropdownSetting` со значениями
  «Выкл / Легкая / Средняя / Тяжелая». На UDP список неактивен, выбранная стратегия
  сохраняется для профиля. Внутренние имена стратегий: `gentle`, `current`, `extended`.
  Справка содержит разделы и абзацы, закрывается обратно в туннель.
- **Автопауза при Wi-Fi** расширяет существующую строку, без дубликата переключателя
  в основном окне настроек. «Настройки автопаузы» открывают три правила, текущую и
  сохранённые сети, ручное добавление, выбор и удаление с подтверждением. Выбор сетей
  неактивен при выключенной автопаузе или правиле «На любом Wi-Fi»; список сохраняется.
  Имя текущей сети читается только при наличии доступа Android, без запросов новых
  разрешений и без сканирования. Если доступа нет, показано «Имя сети недоступно».
- **Экстра потоки** используют исходный `CsqttSettingRow`, сохраняют выбор для
  профиля и недоступны при «Авто ВК». В этом режиме переключатель показан выключенным;
  сохранённый выбор возвращается при выходе из режима. Справка описывает предел 70/100.
- **Экономия батареи**: «Авто / Свой уровень / Выкл». Порог 10, 15, 20, 25, 30, 40,
  50% доступен для своего уровня, неактивен в «Авто» и скрыт в «Выкл». По умолчанию
  «Авто», 30%. Текст справки перенесён из наших существующих настроек.

## Граница макета

Новые значения сохраняются только в отдельном `SharedPreferences`
`native250_ui_preview`. Это не рабочий `SettingsStore`: новые элементы не управляют
Gooby, автопаузой, потоками или блокировками питания. Исходный бегунок и фактический
лимит 100 потоков оригинала не изменены. Перед выпуском нужно отдельно согласовать
подключение этих элементов к существующим реализациям наших функций.

Настройки вставлены в `SettingsTab.kt` и `FloatingToolbar.kt`. Для Compose Preview
добавлены начальные состояния экрана/диалога в `MainScreen` и `FloatingToolbar`,
источник DataStore в памяти без миграций в `SettingsStore`, отключение проверки
обновлений в режиме Preview и корневая Surface из MainActivity. Обычный запуск
использует исходное хранилище. Службы, ядро, ресурсы и тема остаются от `fd936ef`.
Настройки сборки используют SDK/JDK/кэши на E: и ограничивают память Gradle.

Новые элементы используют оригинальные компоненты списка/переключателя, тему,
форму диалога, ширину 92%, отступы и типографику. Добавленные строки увеличивают
содержимое окна настроек; исходная прокрутка сохранена. В Android Studio просмотрены
два Compose Preview, проверены раскрытие Gooby и выбор стратегии. Полная проверка
окон в Android Emulator и попиксельная идентичность не подтверждены. Пользователь
уточнил: для дальнейшего просмотра запускать Android Emulator, а не Android Studio.

## Проверка без APK

Для проверки без упаковки APK с инструментами и временной папкой на E: выполняются:

```text
:app:compileDebugKotlin
:app:testDebugUnitTest --tests com.csqtt.client.ui.Native250WifiNetworksTest
```

Граф задач предварительно проверен через `--dry-run`: сборки и установки APK в нём
нет. `packageDebugResources` обрабатывает ресурсы для компиляции и не создаёт APK.
До разрешения пользователя упаковка была запрещена. Теперь разрешён `assembleDebug`
для arm64-v8a; установка, публикация и release-сборка в эту задачу не входят.

Тесты списка Wi-Fi проверяют удаление вместе с выбором, сохранение по правилам,
защиту от повреждённых данных и ограничение SSID по байтам UTF-8.

## APK принятого макета

- Пакет: `csqtt.quic.amurcanov.native250preview`; он устанавливается отдельно от
  оригинала и не использует его профили.
- Версия: `2.5.0-native250-preview.1` (230), debug-подпись, только arm64-v8a.
- Дополнительные настройки остаются интерфейсными, как описано выше. Сборка APK
  сама по себе не подключает их к Gooby или службам.
- Клиентское ядро и три серверных бинарника восстанавливаются из сохранённого APK
  2.5.0 в игнорируемую `.local/original250`; Rust не пересобирается. Скрипт
  `scripts/prepare_native250_original.ps1 -OriginalApk <путь-на-E:>` проверяет SHA-256
  всего APK и каждого бинарника по исходным provenance-манифестам, сохраняет лицензии.
- После подготовки: `gradle :app:assembleDebug` с Gradle 9.4.1. APK появляется в
  `app/build/outputs/apk/debug/app-debug.apk`; в Git APK и бинарники не добавлять.
