# Классический интерфейс CSQTT с рабочими функциями CSQTTR

Рабочая копия: `E:/csqttr-native250-preview`, ветка `codex/native250-settings-preview`.
Основа Android-интерфейса — `v2.5.0`, коммит `fd936ef`.
Постоянные правила, текущий план и результаты проверок: `E:/csqttr/AGENTS.md`.

Это уже рабочее приложение. Старое описание изолированного интерфейсного макета
относится к историческому APK `2.5.0-native250-preview.1`; оно не описывает ветку сейчас.
Чистый оригинал сохранён отдельно в `E:/csqtt-amurcanov-250`.

## Реализация

- Gooby: один список «Выкл / Легкая / Средняя / Тяжелая», только TCP; стратегии
  `gentle/current/extended` передаются ядру при запуске и восстановлении соединения.
- Автопауза Wi-Fi: любой Wi-Fi, выбранные сети или все кроме выбранных; служба
  сохраняется для возобновления. Для определения SSID нужны разрешения Android,
  для фонового определения — соответствующий доступ в настройках приложения.
- Экстра потоки: по умолчанию выключены, предел 70; включение добавляет 30, предел 100.
  В режиме «Авто ВК» переключатель недоступен. Старые сохранённые значения не сбрасываются.
- Экономия батареи: автоматический режим, заданный уровень или выключение;
  управляет CPU wake locks. Наличие переключателя и успешные тесты не доказывают экономию АКБ.
- Маршрутизация приложений из 59.9: «Все с VPN / Без VPN / С VPN», отдельные наборы
  выбора, готовые списки и очистка текущего списка. Выбранные идут в порядке добавления,
  остальные — по алфавиту. Значки загружаются только для видимых строк. Окно и строки
  используют классическую тему. Пустой список «С VPN» не запускает VPN, как в 59.9.
- Диплинк добавляет свободный профиль вместо перезаписи владельца. Ручной ввод и QR
  сохраняют исходное поведение участника: параметры запуска берутся прямо из ссылки.
- После успешного деплоя пароль синхронизируется в зафиксированный связанный профиль
  туннеля. Неуспешная установка пароль не заменяет.

Терминал и основа логирования остаются из 2.5.0, добавлена обработка сообщений Gooby.
Оптимизации логгера/CPU из 59.10 не переносились. Полное отсутствие задержек интерфейса
не подтверждено. Используются настоящие Android-компоненты, а не HTML со скриншотами.

## Native-комплект и сборка

Клиентский `libclient.so` — сохранённый arm64 runtime `debug.59.9_old`, provenance
`ce0dea9`: UDP отправка 16 КиБ, приём 32 КиБ. Ядро не пересобирается этой Android-сборкой.
Серверный бинарник amd64 и скрипт деплоя взяты из `2e7461d` (59.9); `deploy.sh` должен
оставаться с LF. SHA-256 проверяет `scripts/prepare_native250_runtime.ps1`.

Подготовка: `scripts/prepare_native250_runtime.ps1 -RuntimeApk <сохранённый-APK-59.9_old-на-E:>`.
С JDK 21, Gradle 9.4.1, SDK, кэшами, домашней и временной папками на E: выполняются:

```text
:app:assembleDebug :app:testDebugUnitTest -Pnative250UpdateExisting=true --offline --no-daemon --max-workers=1
```

Вариант обновления: `csqtt.quic.amurcanov.happdebug`, debug-подпись, arm64-v8a.
Без свойства обновления используется отдельный пакет `.native250preview`.
Текущая серия — `2.5.3-classic250.3`. APK: `app/build/outputs/apk/debug/app-debug.apk`;
проверенные копии и приватные резервные копии хранятся только в игнорируемой `.local`.
Нельзя устанавливать с удалением данных или сбрасывать Android Keystore.

Для просмотра использовать Android Emulator или согласованную проверку телефона;
Android Studio не открывать без нового запроса. Перед каждым деплоем или удалением
сервера попросить пользователя запустить Happ и дождаться готовности. Сам Happ и
его настройки не менять. Фактические проверки трафика через каскад не считать
измерением прямого соединения или чистым сравнением производительности.
